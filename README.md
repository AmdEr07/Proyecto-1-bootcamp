# Proyecto-1-bootcamp

Proyecto frontend desarrollado durante bootcamp de desarrollo web.

Web temática de chocolatería artesanal creada con HTML, CSS y JavaScript, incluyendo navegación multipágina, formulario de contacto validado, diseño responsive y organización del proyecto mediante Git y GitHub.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Navegación entre páginas
- Formulario de contacto interactivo
- Validación básica con JavaScript
- Diseño responsive
- Organización de imágenes y recursos
